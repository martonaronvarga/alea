# Benchmark evidence

Reports, manifests and provenance are retained in Git. Compressed raw payloads
are stored separately and listed in [payloads.json](payloads.json). Restore the
catalog-matching files before using report-local archive links or unpack commands;
see [storage and restoration](../workspace.md). Original benchmark identities,
failures and checksums are preserved.

Start with the [walltime parity report](walltime-parity-2026-10-23/README.md) for
the latest native NUTS comparison, or the [M16 evidence guide](m16/README.md) for
the broader baseline and research matrices. Results describe their measured
configurations and source snapshots, rather than a universal sampler ranking.
