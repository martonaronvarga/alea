# Executed BlackJAX endpoint references

Historical increment-8 record. [M3 completion](m3-hmc-completion.md) extends this
reference to 90 endpoints and adds independently executed sampling comparisons.

Roadmap increment 8, 2026-09-27. These fixtures were generated by executing
BlackJAX, independently of Rust output. They validate deterministic phase
evolution, not cross-library random streams or statistical convergence.

## Provenance and reproduction

- BlackJAX **1.5**, JAX and jaxlib **0.9.2**, Python **3.13.12**.
- CPU backend, explicitly enabled float64, no whole-step `jax.jit` wrapper.
- Generated and reproduced byte-for-byte on x86-64 Linux (Intel i5-8250U).
- [Pinned Nix environment](../tools/blackjax-reference/default.nix) uses nixpkgs
  `68d8aa3d661f0e6bd5862291b5bb263b2a6595c9` with a content hash, independently
  of future workspace lock updates. It pins transitive dependencies, including
  NumPy 2.4.2 and SciPy 1.17.1. It does not modify the default development shell.
- JAX and BlackJAX packages both install a top-level `docs/` tree. The environment
  gives BlackJAX lower link priority to resolve that documentation-file collision;
  neither numerical implementation is patched.

The [generator](../tools/blackjax-reference/generate.py) calls BlackJAX's
[`new_integrator_state` and `velocity_verlet` at release 1.5](https://github.com/blackjax-devs/blackjax/blob/1.5/blackjax/mcmc/integrators.py).
JAX differentiates both the log density and `K(p) = pᵀ M⁻¹ p / 2`; the generator
does not manually implement leapfrog or supply analytic gradients. Float64 must
be explicitly enabled because [JAX defaults to 32-bit types](https://docs.jax.dev/en/latest/default_dtypes.html).

Regeneration intentionally requires exact text equality on the recorded environment.
Other architectures/compiler builds may change the final bits; inspect differences
and record the environment rather than blindly replacing the fixture. Rust tests
use numerical tolerances. The generator rejects different BlackJAX/JAX versions;
version upgrades require deliberate pin, fixture, and provenance updates.

## Cases and conventions

There are 36 rows: two targets × three masses × signed steps `±0.125` × step
counts `1, 5, 11`. Every case starts at `q = [0.7, -0.4]`, `p = [0.3, 1.1]`.
No momentum flip or Metropolis selection is applied to the recorded endpoint.

Densities omit additive constants:

- Correlated Gaussian: `z = (q1 - 0.6 q0) / 0.8`, `logp = -(q0² + z²)/2`.
- Banana: `z = q1 - 0.4(q0² - 1)`, `logp = -(q0² + z²)/2`.

| Mass type | Lower factor L (rows shown) | Mass M = LLᵀ |
|---|---|---|
| Identity | `[[1, 0], [0, 1]]` | identity |
| Diagonal | `[[2, 0], [0, 0.5]]` | `diag(4, 0.25)` |
| Dense | `[[1.5, 0], [0.4, 0.8]]` | `[[2.25, 0.6], [0.6, 0.8]]` |

Alea takes mass, not inverse mass. The generator independently computes
`inverse(LLᵀ)` in JAX for the kinetic function. The CSV records lower-factor and
symmetric inverse-mass entries. Tests reconstruct Alea's mass (dense factor in
column-major order) and compare inverse actions on both basis vectors before
integrating. This explicitly checks the convention rather than assuming it.

The [CSV](../crates/runtime/tests/fixtures/blackjax-1.5.csv) contains initial and
endpoint position, momentum, log density, gradient, and Hamiltonian, along with
the full trajectory configuration. Decimal floats round-trip to f64.

## Rust checks and limits

Three private [unit tests](../crates/runtime/src/hamiltonian/reference_tests.rs)
invoke the **production** `Phase::step` using its existing test-only explicit
momentum entry point. They compare all eight state/energy fields at initialization
and at the endpoint, then integrate back with the opposite signed step and check
recovery. Rust target gradients are analytic, independently of JAX autodiff.

Every numeric comparison uses `abs(actual - expected) <= 2e-12 * (1 + abs(expected))`
and rejects non-finite actual values. This accommodates f64 evaluation-order
differences across scalar/SIMD/Faer/BLAS without accepting f32-sized errors.
Coverage checks require all 36 distinct configurations; missing, duplicated,
unknown, malformed, or non-finite fixture rows fail tests.

The test module and embedded CSV compile only under `cfg(test)`. No public API,
production instructions, unsafe code, Rust dependencies, or hot-path allocations
are added. Python is an optional regeneration tool, not a Rust test/build dependency.

This closes the **deterministic external endpoint** subgate only. It does not
validate momentum RNG/MH policy against BlackJAX, certify stationary moments or
ESS, test logistic/funnel/rotated ill-conditioning, or validate std::autodiff/Enzyme.
M3 as a whole and the preceding CI/FFI/AD gates remain open.
